## 如何重新运行

1. 安装 Python 3.10 以上 (你的电脑上已有 Python / Jupyter)。
2. 在本文件夹打开终端：`pip install -r requirements.txt`
3. Windows 双击 `run_all.bat`，或者在 `src` 文件夹里逐个运行：
   `python run_sweep.py` → `python run_sweep.py --only charge --h 50` (冷却敏感性) → `python run_benchmark.py` → `python run_mesh_check.py` → `python run_validation.py` → `python make_figures.py` → `python export_matlab.py`
4. 快速测试 (约 10 秒)：`python run_sweep.py --only charge --quick`
5. MATLAB：打开 `matlab/SEP798_postprocess.m` 点 Run。

整个研究在 4 核云服务器上约需 40–60 分钟，其中大部分时间花在 UDDS 工况的 DFN 仿真上。改倍率、温度、判定阈值等，只需改 `src/config.py`。

## 结果文件说明 (results/)

| 文件 | 内容 |
|---|---|
| `runs_charge.csv` / `runs_discharge.csv` / `runs_udds.csv` / `runs_charge_h50.csv` (h = 50 W/m²K) | 每一次仿真一行：模型、工况、状态、求解时间、峰值温度、最小负极电位、最小电解液浓度等 |
| `errors_charge.csv` / `errors_discharge.csv` / `errors_udds.csv` / `errors_charge_h50.csv` | SPM / SPMe 相对 DFN 的全部误差指标 + 适用性分级 (`class`: 0 适用, 1 勉强, 2 不适用, 3 模型失效) |
| `benchmark.csv`, `benchmark_summary.csv` | 计算时间基准 (每个工况重复 5 次取中位数) 和加速比 |
| `mesh_check.csv` | DFN 默认网格 vs 加密网格的差异 |
| `validation.csv` | 与 LG M50T 实测数据的电压 / 温度误差 (raw 与 capacity-aligned 两种) |
| `traces_*.pkl`, `validation_traces.pkl` | 每次仿真的完整时间曲线 (Python pickle)，画图用；`traces_charge_h50.pkl.gz` 因为太大做了 gzip 压缩，代码会自动读取 |
| `log_*.txt` | 运行日志 |
| `matlab/*.mat` | 供 MATLAB 读取的同样数据 |
