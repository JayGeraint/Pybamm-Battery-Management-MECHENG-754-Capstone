# Chen2020 experimental data

Source: Chen, C.-H., Brosa Planella, F., O'Regan, K., Gastol, D., Widanage, W. D., and Kendrick, E. (2020), Experimental data for Development of Experimental Techniques for Parameterization of Multi-scale Lithium-ion Battery Models.

Version DOI: https://doi.org/10.5281/zenodo.4032561

Paper DOI: https://doi.org/10.1149/1945-7111/ab9050

License recorded in repository metadata: CC BY 4.0. The three original files are unchanged. `processed/` contains derived files, generated by `prepare_data.py`; these convert unsigned source current using the C/D mode and retain duplicate-time flags. Cite the dataset and paper when using these data. Full repository metadata is retained in `raw/record_metadata.json`.

The source includes three LG M50 cells. Discharge steps 7, 12, 17 and 22 correspond approximately to 0.1C, 0.5C, 1C and 1.5C. Charging is approximately 1.5 A (0.3C for 5 Ah), not 3C. The first discharge step 2 is preconditioning, not the full-capacity test.

The original current values are unsigned magnitudes. Use C or D in the Md column to determine charge or discharge before converting to PyBaMM's discharge-positive convention. The files contain end records with duplicate timestamps; the cleaning script retains and flags them, while the validation script removes duplicate times within each discharge step. These measurements do not cover 3C fast charging. Measured surface thermocouple temperature is not the same physical quantity as the model's volume-average temperature. Because these data accompany the Chen2020 parameterization paper, they support a reproduction check rather than independent external validation on a new cell population.
